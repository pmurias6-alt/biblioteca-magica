# Biblioteca màgica

Web de libros inventados para Primaria (Català, Castellano, English) con preguntas por capítulo,
refuerzo adaptativo y audio. Sin registro: el progreso se guarda en el dispositivo.

- `public/` — la web (HTML + JS + imágenes). Cloudflare Workers la sirve tal cual.
- `public/books/` — un fichero por curso con los libros y sus preguntas.
- `public/img/` — ilustraciones (`<id-libro>-<página>.jpg`) y salas (`room-<curso>.jpg`).

Todo gratuito: sin APIs de pago.
